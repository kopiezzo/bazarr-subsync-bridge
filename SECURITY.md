# Security policy

## Supported branch

Security fixes target the latest default branch state.

## Report a vulnerability

Do not open a public issue for security problems.

Report it privately with GitHub's private vulnerability reporting: open the repository's Security tab and choose Report a vulnerability, or go to https://github.com/kopiezzo/bazarr-subsync-bridge/security/advisories/new. Include:

- impact
- reproduction steps
- affected files or configuration
- relevant logs with secrets removed
- suggested fix, if known

## Secrets and runtime data

Do not share:

- `.env` files
- Plex tokens
- internal media paths
- queue payloads or logs containing private file names

## Response

This project is maintained on a best-effort basis. Confirmed security issues are handled privately first and disclosed only after a fix or mitigation is ready.
